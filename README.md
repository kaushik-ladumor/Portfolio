# ✨ Kaushik's Personal Portfolio

A sleek, high-contrast, and fully responsive personal portfolio website built with modern technologies. This project showcases my professional experience, technical skills, and featured projects with a premium dark-themed aesthetic.

---

## 🚀 Live Demo
**Check it out here:** [👉[https://kaushik-ladumor-portfolio.netlify.app/](https://kaushik-ladumor-portfolio.netlify.app/)👈](#)

---

## 🎨 Design Aesthetic
- **Theme:** High-contrast Dark Orange & Slate (`#0a0a0a` / `#f97316`)
- **Typography:** Poppins (via Google Fonts)
- **Features:** 
  - Dynamic Typewriter Animation
  - Glassmorphic UI Components
  - Custom Scroll-reveal Animations
  - Fully Mobile-Responsive Navigation
  - Functional Contact Form via **EmailJS**

---

## 🛠️ Tech Stack

### Frontend
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Animations:** CSS Keyframes + Intersection Observer API
- **Routing:** React Router DOM

### Backend / Services
- **Forms:** EmailJS Browser Integration

## 📥 Getting Started

### Prerequisites
- Node.js (v18.0 or higher)
- npm  

### Installation
1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   ```

2. **Navigate to the project directory:**
   ```bash
   cd portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Initialize Tailwind CSS (v4):**
   ```bash
   npm install tailwindcss @tailwindcss/vite
   ```

5. **Start the development server:**
   ```bash
   npm run dev
   ```

## ⚙️ Configuration (EmailJS)
To make the contact form functional, replace the placeholders in `src/components/Contact.jsx` with your own keys:
```javascript
const EMAILJS_SERVICE_ID = "your_service_id";
const EMAILJS_TEMPLATE_ID = "your_template_id";
const EMAILJS_PUBLIC_KEY = "your_public_key";
```
